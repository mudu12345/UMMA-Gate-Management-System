# UMMA Gate Management System

A Windows desktop application built with **C# Windows Forms** to help
manage gate registration and movement records at UMMA University.

## Features

-   Register staff, students, visitors, and vehicles
-   Record entry and exit movements
-   Search records by name, ID number, or vehicle number
-   Delete selected records
-   Save and load gate records using CSV files

## Download

Download the latest release from the repository's **Releases** page:

-   Open the repository on GitHub.
-   Select **Releases**.
-   Open **UMMA Gate Management System v1.0.0**.
-   Under **Assets**, download `UMMA-Gate-Management-System-v1.0.0.zip`.

## Installation on Windows

1.  Download `UMMA-Gate-Management-System-v1.0.0.zip` from **Releases →
    Assets**.
2.  Right-click the ZIP file and choose **Extract All...**.
3.  Open the extracted folder.
4.  Double-click `UmmaGateManagement.exe` to launch the application.
5.  Keep the other files from the ZIP in the same folder as the `.exe`;
    do not move the `.exe` by itself.

**If the application does not start:** confirm that you extracted all
files. If Windows reports that a required .NET runtime is missing,
install the matching **.NET Desktop Runtime** and try again.

## Data storage

The application uses CSV file storage for gate records. Keep a backup of
any records you need. Do not upload real visitor or student information
to a public GitHub repository.
